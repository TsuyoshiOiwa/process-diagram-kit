# BPMN 図レイアウト調整 (d2-bpmn)

- 要素・フローの定義方法は `bpmn-diagram` スキルを参照 (本スキルは**配置のみ**を扱う)
- 座標調整の実績ある手順と tala レイアウトの挙動知見を集約している
- 実例: `works/library-usecase01.d2` (調整履歴: `history.txt`)

## ツール

| コマンド | 用途 |
|---|---|
| `./scripts/render.sh <file.d2> [png\|svg]` | 単一ファイルを tala + IPA フォントで `out/` に高速ビルド (反復確認用) |
| `python3 scripts/d2setpos.py FILE NODE.top=N NODE.left=M ...` | ノード座標の一括設定 (`--unset NODE.top` で行削除) |
| `make fmt` / `make check` | 整形・構文検証 |
| `make buildpng` | 全図を `out/` に PNG 出力 (最終確認) |
| `make watch FILE=works/xxx.d2` | ライブプレビュー (ポート 39981) |

## 調整ワークフロー (描画→確認→修正の反復)

1. 現状を描画して目視する: `./scripts/render.sh works/xxx.d2` → 出力画像を Read で確認
2. 問題 (交差・大回り・未整列・余白過多) を 1 箇所ずつ特定する
3. `scripts/d2setpos.py` で座標を変更する
   (既存行はインデントを維持して値だけ置換、無ければノード定義行の直後に挿入)
4. `make fmt` → 再描画して確認する
5. 収束したら `make check` と `make buildpng` で仕上げる

注意: スクリプトや sed/python での一括置換は、インデント違いで**無音で失敗**することがある。
編集後は `grep` で反映を必ず確認してから描画する。

## 座標の目安 (規約)

- ルートは `direction: down` (プール縦積み + メッセージ縦流しに合う)
- プールは `top` で縦積み、レーンはプール内の `top` で縦積み
- 行位置: `top: 0 / 320 / 640 ...` (1 段 ≈ 300。分岐・例外系の行は主行の下に 320 ずらして足す)
- 列位置: `left` は 260〜300 刻み (タスク幅 ≈ 260)
- プール間メッセージ用に「専用列」を確保し、**両端ノードの `left` を一致させる**

## tala の経路挙動と定石

- **両端の `left` を揃えるとメッセージフローは縦直線になる**
  プール間メッセージは必ず縦揃えを狙う。ずらすと斜め・大回りになる
- **レーンを横断する経路は、通路が空いていても外周へ大回りする**
  レーン境界の交差にペナルティがあり、ノード衝突の有無では決まらない。
  → 横断が必要なメッセージは、両端を「横断したいレーンの幅より外側 (右端など)」に置き、
  レーン外の余白を通る経路に変える
- **交差が出たら行を分離する**
  縦線と横線が交わる場合、どちらかのチェーンを別の `top` 行へ移す
  (例: ゲートウェイ直下の例外終了は 1 段目、時間のかかる後続チェーンは最下段)
- **レーン順の入替は他のメッセージを壊すことがある**
  1 本の直線化と引き換えに 3 本が大回りした実績あり。入替時は全メッセージフローの経路を再確認する
- 長い戻りエッジ (合流・リワーク) は L 字でもよい。**無理な直線化より「交差ゼロ + 整列」を優先**する

## 配置変更に伴う D2 の落とし穴

- レーン横断のシーケンスフローはプール階層にフルパスで書く。
  レーンブロック内に他レーン参照 (`ACT-003.TSK-003003` 等) を書くと、
  D2 はスコープ相対で解決するため**レーン内に意図しない同名コンテナが新規生成される**
- コンテナ (プール・レーン) のサイズは子要素から自動決定され、直接指定は不可。
  レーン幅を変えたい場合は内容物の `left` を動かす
- アイコン (marker) の位置はレイアウトエンジン任せ (座標指定不可)
